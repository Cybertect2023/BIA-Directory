- Lighthouse Tutoring has multiple locations. Its site-wide coordinates describe Picton, not Stirling. The Stirling address is separately published; the 8 Mill Street property pin comes from co-located Blue Collar Therapy’s operator directions. Picton metadata was deliberately not used.
- OSM still calls 25 Mill Street “The Village Junction”; the exact address is used, with the canonical BIA name “The Vintage Junction”.
- An older OSM Cafe 23 node is not used to establish the current Smokin’ Barrel location; its operator’s own GeoCoordinates are used.
- Source review does not constitute a field survey or guarantee that every business is operating today. Do not publish live/open-now badges from this dataset.
- OSM records retain older survey dates in many cases. Verification date records when this project reviewed the evidence, not when a site visit occurred.
